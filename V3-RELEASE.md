## Installation and hosting

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
pnpm dev
```

The full-stack app uses React, Vite, Express, tRPC and Drizzle. Configure database, Manus OAuth, cookie signing, model and storage variables privately. Never commit `.env` or credentials. For a new database, apply existing migrations; do not blindly replay table creation on production. `pnpm start` serves the compiled Node application.

Artwork uses managed `/manus-storage/...` references. The ZIP excludes image binaries, credentials, dependencies and build artifacts. Other hosting requires deliberate asset migration and compatible OAuth/model/storage setup; this is not an unconfigured static deployment.
