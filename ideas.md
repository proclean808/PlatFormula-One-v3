# PlatFormula.One Restoration Reference

This project is a **fidelity restoration**, not a redesign. The ground-truth experience is the verified `platformula1-v2` application at commit `63c568d473af2f0c2c8f292fa5c7d6cbcc73ef55`, which matches the user’s saved work.

## Chosen Direction: Racing-Control Founder Intelligence

**Design Movement.** The existing product combines a Formula 1 control-room mood with a high-density founder operating system. The restore must preserve this exact character rather than introduce a new visual direction.

**Core Principles.** Maintain the dark, high-contrast application shell; retain the colorful gradient hierarchy that distinguishes each founder workflow; preserve the fast, information-rich multi-tab journey; and keep the dashboard as the central launch point for the platform.

**Color Philosophy.** Near-black surfaces establish the cockpit-like base. Purple, pink, cyan, emerald, orange, and blue gradients act as deliberate route markers for different tools, deadlines, and resources. The color system communicates navigation and priority—not decoration alone.

**Layout Paradigm.** Retain the sequential founder journey, the F1-framed hero, the row of high-impact dashboard metric tiles, the accelerator-card collection, and the responsive mobile drawer.

**Signature Elements.** The F1 hero imagery, the "Next YC Deadline" gradient tile that links to the Y Combinator application, and the mobile hamburger drawer with individually colored navigation labels must remain intact.

**Interaction Philosophy.** Navigation should stay direct and task-oriented. The deadline tile, founder-journey tiles, accelerator actions, and tab controls must retain their existing destinations and responsiveness.

**Animation.** Preserve existing restrained hover and transition behavior. Avoid new decorative motion so the restored app feels exactly as the saved version did.

**Typography System.** Preserve the source application’s current typography and hierarchy. Large, high-weight gradient display text identifies the platform, while compact neutral labels support dense founder operations.

**Brand Essence.** PlatFormula.ONE is a founder intelligence platform that puts accelerator resources, startup tools, and practical application workflows on one high-speed operating surface. **Focused, capable, and kinetic.**

**Brand Voice.** Keep concise, decisive product language: “Every tool. Every accelerator. Every answer. One platform.” and “Next YC Deadline — Apply to Y Combinator.”

**Wordmark & Logo.** Preserve the existing PlatFormula.ONE wordmark treatment and racing visual anchors from the verified source. Do not substitute a new mark during restoration.

**Signature Brand Color.** The blue-to-magenta gradient used in the PlatFormula.ONE title remains the identifiable brand color treatment.

## Restoration Constraints

The selected source version is the newer `platformula1-v2` repository, not the earlier public `PlatFormula-One-v2` repository. Preserve its behavior and content unchanged except for required hosting-compatible asset paths and non-rendered documentation comments. The former `manusvm.computer` address is a temporary VM URL and cannot be independently reactivated from source code; if it cannot be reassigned in project settings, the same verified application will be ready for publish at the managed project address.
